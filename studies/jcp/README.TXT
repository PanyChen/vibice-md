## Title: Freezing under motion: How surface vibrations suppress ice nucleation in water nanofilms ##

Authors:  Pengxu Chen, Patrick Sullivan, Rohit Pillai, Saikat Datta
This data folder contains the output data from all molecular dynamics simulations carried out in this paper.

Folders ‘FIG2’, ‘FIG3’, ‘FIG4’, ‘FIG5’, ‘FIG6’, ‘FIG7’ contain all the data and MATLAB scripts necessary to recreate the respective figures.

Folder ‘Sample_case’ contains sample LAMMPS input files and associated data file which can be used to run an NEMD vibration simulation.

Format of files:
All files with .txt are the text files containing the raw data necessary to recreate a given figure.
All files with the .lammpstrj extension are LAMMPS dump files containing molecular trajectory data, which can be processed to reproduce the corresponding figure.
All files with .m are the MATLAB scripts to generate the figures in the paper.
